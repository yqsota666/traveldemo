# 新服务器部署依赖清单

本文档说明从 GitHub 拉取 `traveldemo` 后，**需要在目标服务器上自行安装/下载** 的软件与依赖。  
仓库内已包含**源代码、SQL 建表与初始数据脚本**，**不包含** `node_modules`、Maven 本地仓库、MySQL 数据文件等运行时产物。

---

## 一、系统级软件（必装）

| 软件 | 推荐版本 | 用途 | 安装示例（CentOS / Alibaba Cloud Linux） |
|------|----------|------|------------------------------------------|
| **Git** | 2.x | 拉取代码 | `dnf install -y git` |
| **MySQL** | 8.0.x | 业务数据库 | `dnf install -y mysql-server` → `systemctl enable --now mysqld` |
| **Java JDK** | **11** | 运行 Spring Boot | `dnf install -y java-11-openjdk-devel` |
| **Maven** | 3.6+ | 编译后端、下载 Jar 依赖 | `dnf install -y maven` |
| **Node.js** | **18 LTS 或 20 LTS** | 管理端前端 `npm install` | 见下方 Node 安装说明 |
| **npm** | 随 Node 自带 | 安装前端 npm 包 | 一般无需单独装 |

### 可选（仅开发小程序时）

| 软件 | 用途 |
|------|------|
| **pnpm** 10.x | `travel-miniapp` 包管理（`package.json` 指定 `pnpm@10.33.2`） |
| **微信开发者工具** | 本地预览 / 上传小程序 |

### 生产环境可选

| 软件 | 用途 |
|------|------|
| **Nginx** | 托管管理端前端静态资源 `travel-admin-web/dist` |
| **systemd / supervisord** | 守护后端 Java 进程 |

## 二、MySQL

### 2.1 服务与库

- **主机**：`127.0.0.1`（与 `application.yml` 一致，远程库请改配置）
- **端口**：`3306`
- **数据库名**：`travel_demo`
- **默认账号**：`root` / `root`（**生产务必修改密码**，并同步改后端配置）

### 2.2 仓库内 SQL 脚本（按顺序执行）

路径均在 `travel-admin-backend/scripts/sql/`：

| 顺序 | 文件 | 说明 |
|------|------|------|
| 1 | `00_create_database.sql` | 创建 `travel_demo` 库 |
| 2 | `init_admin_schema.sql` | 管理后台全部表结构 |
| 3 | `init_admin_seed.sql` | 角色、权限、演示账号与样例数据 |

一键脚本：

```bash
cd travel-admin-backend/scripts
chmod +x install-db.sh
./install-db.sh
```

### 2.3 小程序用户端表（若同时部署 `travel-backend`）

```bash
mysql -uroot -p travel_demo < travel-backend/scripts/sql/create_travel_auth_tables.sql
```

### 2.4 演示账号（管理后台）

| 账号 | 密码 | 说明 |
|------|------|------|
| superadmin | admin123 | 超级管理员 |
| director01 | admin123 | 高层管理 |
| sales01 | admin123 | 销售 |

## 三、管理后台（本次重点）

### 3.1 目录与端口

| 目录 | 类型 | 默认端口 |
|------|------|----------|
| `travel-admin-backend/` | Java / Spring Boot 2.7.18 | **8091** |
| `travel-admin-web/` | React + Vite | 开发 **5174** |

### 3.2 后端：Maven 会自动下载的依赖

在 `travel-admin-backend/` 执行 `mvn package` 或 `mvn spring-boot:run` 时，Maven 从中央仓库拉取（**无需手动下载**），主要包括：

- Spring Boot 2.7.18（web、jdbc、validation、security）
- MySQL Connector/J **8.0.33**
- JJWT **0.11.5**（api / impl / jackson）

完整声明见：`travel-admin-backend/pom.xml`

```bash
cd travel-admin-backend
mvn -DskipTests package          # 首次会下载依赖，需要网络
mvn spring-boot:run              # 启动 API，端口 8091
```

配置文件：`travel-admin-backend/src/main/resources/application.yml`

### 3.3 前端：npm 需要安装的包

在 `travel-admin-web/` 执行 `npm install`（或 `npm ci`）时安装，锁文件为 `package-lock.json`：

**生产依赖**

| 包名 | 用途 |
|------|------|
| react / react-dom ^18.3 | UI 框架 |
| react-router-dom ^6.28 | 路由 |
| @arco-design/web-react ^2.66 | 组件库 |
| axios ^1.7 | HTTP 请求 |
| dayjs ^1.11 | 日期处理 |

**开发依赖**

| 包名 | 用途 |
|------|------|
| vite ^5.4 | 构建与 dev server |
| typescript ^5.6 | 类型检查 |
| @vitejs/plugin-react ^4.3 | React 插件 |

```bash
cd travel-admin-web
npm ci                           # 或 npm install
npm run dev                      # 开发：http://0.0.0.0:5174
npm run build                    # 生产：输出 dist/
```

API 代理：开发时 Vite 将 `/api` 转发到 `http://127.0.0.1:8091`（见 `vite.config.ts`）。

## 四、小程序与其它模块（可选）

### 4.1 小程序前端 `travel-miniapp`

- **包管理**：pnpm（推荐 `corepack enable` 后使用项目锁定版本）
- **框架**：Taro 3.x + React

```bash
cd travel-miniapp
corepack enable
pnpm install
pnpm run dev:weapp
```

用**微信开发者工具**打开 `travel-miniapp` 或编译后的 `dist/weapp`。

### 4.2 小程序后端 `travel-backend`

- Java 11 + Maven，端口 **8080**
- 共用数据库 `travel_demo`

```bash
cd travel-backend
mvn spring-boot:run
```

## 六、推荐部署顺序（新机器）

```bash
# 1. 安装系统软件：git、mysql-server、java-11、maven、nodejs
# 2. 克隆仓库
git clone https://github.com/yqsota666/traveldemo.git
cd traveldemo
git checkout feature/admin-dashboard-setup   # 或 main

# 3. 初始化数据库
cd travel-admin-backend/scripts && ./install-db.sh

# 4. 启动管理后台后端
cd ../../travel-admin-backend && mvn spring-boot:run

# 5. 启动管理后台前端（另开终端）
cd ../travel-admin-web && npm ci && npm run dev
```

浏览器访问：`http://服务器IP:5174`

## 七、内存与磁盘参考

| 场景 | 建议 |
|------|------|
| 仅 `mvn package` | 预留 **≥ 1GB** 可用内存 |
| `npm ci`（管理端前端） | 预留 **≥ 512MB** 可用内存 |
| MySQL + 后端 + 前端同时运行 | 建议 **≥ 2GB** 总内存 |
| 磁盘 | 代码 + Maven 缓存 + node_modules 约 **500MB～1.5GB** |

内存紧张时：先在较大机器完成 `mvn package` 与 `npm run build`，再将 `target/*.jar` 与 `travel-admin-web/dist/` 拷到目标机，目标机可不再执行 Maven/npm。

## 九、配置修改检查项

部署到新环境前请确认：

- [ ] MySQL 账号密码与 `travel-admin-backend/src/main/resources/application.yml` 一致
- [ ] 生产环境修改 `admin.jwt.secret`
- [ ] 防火墙放行 **8091**（API）、**5174**（开发前端）或 Nginx 端口
- [ ] 演示账号密码上线前改为强密码
