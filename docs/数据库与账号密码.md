# 数据库与账号密码速查

> 本文档汇总 **traveldemo** 项目当前环境的连接信息与登录密码，便于本地/测试环境查阅。  
> **生产环境务必修改所有默认密码**，并同步更新后端 `application.yml`。

---

## MySQL 数据库连接

| 项 | 值 |
|----|-----|
| 主机 | `127.0.0.1` |
| 端口 | `3306` |
| 数据库名 | `travel_demo` |
| 用户名 | `root` |
| 密码 | `root` |

**命令行连接：**

```bash
mysql -h127.0.0.1 -P3306 -uroot -proot travel_demo
```

**JDBC（两个后端共用）：**

```
jdbc:mysql://127.0.0.1:3306/travel_demo?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
```

配置文件位置：

- `travel-admin-backend/src/main/resources/application.yml`
- `travel-backend/src/main/resources/application.yml`

初始化脚本环境变量（`travel-admin-backend/scripts/install-db.sh`）默认与上表一致：`DB_USER=root`，`DB_PASS=root`。

## 管理后台登录账号（`admin_user` 表）

当前测试环境密码已统一为 **`123456`**（由 `reset-test-passwords.sql` 重置）。

| 角色 | 登录名 | 密码 | 说明 |
|------|--------|------|------|
| 超级管理员 | `superadmin` | `123456` | 角色 `SUPER_ADMIN` |
| 高层管理 | `director01` | `123456` | 角色 `SENIOR_ADMIN` |
| 销售 | `sales01` | `123456` | 角色 `SALES`，工作台 2 单 |
| 销售 | `sales02` | `123456` | 角色 `SALES`，工作台 3 单（演示数据见 `seed-sales02-demo.sql`） |

**登录页：** [http://localhost:5174/login](http://localhost:5174/login)（需 Cursor 端口转发 5174）

**密码重置脚本（登录失败时执行）：**

```bash
cd /root/traveldemo
mysql -uroot -proot travel_demo < travel-admin-backend/scripts/reset-test-passwords.sql
```

> **说明：** 种子数据 `init_admin_seed.sql` 里初始密码为 `admin123`（bcrypt 哈希），执行上述重置脚本后会变为 `123456`。

## 相关说明

| 内容 | 说明 |
|------|------|
| `last_login_at` | 仅在后端**登录成功**时更新；失败不写该字段 |
| 登录审计 | 表 `admin_login_log`，字段 `login_status`：`SUCCESS` / `FAILED` |
| 小程序用户表 | `travel_user` 等需单独执行 `travel-backend/scripts/sql/create_travel_auth_tables.sql` 建表，与上表 MySQL 账号无关 |
