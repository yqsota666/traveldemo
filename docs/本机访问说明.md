# 本机访问管理后台（Cursor 远程开发）

## 只需转发 1 个端口

在 Cursor 底部 **「端口 / Ports」** 里转发：

| 端口 | 说明 |
|------|------|
| **5174** | 前端页面 + 接口（接口自动代理到后端，不用再转 8091） |

点击 5174 旁的 **「在浏览器中打开」**，或自己访问：

```
http://localhost:5174/login
```

## 登录

页面已默认填好 `director01` / `123456`，点 **登录** 或 **高层管理（director01）** 即可。

## 若仍提示 Network Error

1. 确认 Ports 里 **5174 状态为已转发**（绿色/Active）
2. **Ctrl + F5** 强制刷新页面
3. 在服务器终端执行重启脚本：

```bash
cd /root/traveldemo && ./start-admin.sh
```

4. 仍不行：在 Ports 里**删掉 5174 再重新添加转发**，然后重新打开浏览器

## 不要用这些地址

- `172.26.x.x` — 内网，你电脑连不上
- 公网 IP — 安全组未开放会超时
