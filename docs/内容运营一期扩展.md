# 内容运营一期扩展

## 目标与约束

- 底层只使用一份 MySQL（`travel_demo`）。
- `travel-admin-backend` 为唯一内容写入口，提供全部 CRUD。
- 本期不实现 `travel-backend` 面向 C 端的读取接口；数据模型为后续复用预留。
- **不修改 C 端 UI**；仅预留静态块与表的映射关系。

## 范围

| 模块 | 说明 |
|------|------|
| 轮播图 | 首页 banner，本期不跳转 |
| 城市 | 最高层级，景点/住宿/租车/商品均关联城市 |
| 景点 | 含首页推荐标记 `home_recommended` |
| 住宿 / 租车 | 通用字段，关联城市 |
| 文创商品 | 价格、外链、图集、推荐、上下架 |
| About Us | 公司简介单页配置；讲解员列表；案例截图（小红书/微信等） |
| 行程提醒 | 出行须知等内容 |
| 在线咨询 | 按钮文案、客服二维码、电话 |

## 已确认规则

- **审核**：所有内容需审核；状态为 `DRAFT` / `PENDING` / `PUBLISHED` / `OFFLINE`。
- **角色**：普通销售录入并提交审核；高层管理员与超级管理员可审核通过、下架。
- **销售可见**：可查看全部；未提交审核前可编辑全部；提交后审核完成前不可删改。
- **删除**：统一软删除。
- **审核记录**：保留提交人、审核人、意见、时间。
- **排序**：支持拖拽排序（列表接口 `sort-order` 批量更新）。
- **推荐景点**：景点表 `home_recommended` 标记，不单独建表。
- **上传**：统一格式/大小校验，超限服务端压缩（JPEG/PNG，最大约 2MB）。
- **地址**：存文本地址，C 端后续接高德搜索跳转。
- **详情**：普通字段 + 长文本，不用富文本编辑器。
- **批量**：批量删除、批量提交审核、批量上架/下架。
